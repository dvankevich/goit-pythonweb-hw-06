# goit-pythonweb-hw-06

# CLI CRUD Утиліта для Навчальної БД

Це консольна утиліта для управління базою даних навчального закладу. Вона дозволяє виконувати базові CRUD-операції (створення, читання, оновлення, видалення) для викладачів, груп, студентів, предметів та оцінок безпосередньо з командного рядка.

## Вимоги
* Python 3.x
* SQLAlchemy
* Налаштоване підключення до бази даних (файл `connect.py` та `models.py`)

## Синтаксис
```bash
python main.py -a <action> -m <model> [додаткові аргументи]
```

### Основні параметри:
* `-a`, `--action` *(обов'язковий)*: Дія, яку потрібно виконати. Варіанти: `create`, `list`, `update`, `remove`.
* `-m`, `--model` *(обов'язковий)*: Модель даних. Варіанти: `Teacher`, `Group`, `Student`, `Subject`, `Grade`.

### Додаткові аргументи:
Залежно від обраної моделі та дії, можуть знадобитися додаткові параметри:
* `--id` — ID запису (обов'язково для `update` та `remove`).
* `-n`, `--name` — Ім'я викладача/студента або назва групи/предмета.
* `--group_id` — ID групи (для створення/оновлення студента).
* `--teacher_id` — ID викладача (для створення/оновлення предмета).
* `--student_id` — ID студента (для створення/оновлення оцінки).
* `--subject_id` — ID предмета (для створення/оновлення оцінки).
* `--grade` — Значення оцінки.

---

## Приклади використання

### 1. Створення (Create)
Створення викладача:
```bash
python main.py -a create -m Teacher -n "Іваненко І.І."
```

Створення групи:
```bash
python main.py -a create -m Group -n "КН-21"
```

Створення предмета (потребує ID викладача):
```bash
python main.py -a create -m Subject -n "Вища математика" --teacher_id 1
```

Створення студента (потребує ID групи):
```bash
python main.py -a create -m Student -n "Петренко Петро" --group_id 1
```

Виставлення оцінки (потребує ID студента, ID предмета та саму оцінку):
```bash
python main.py -a create -m Grade --grade 12 --student_id 1 --subject_id 1
```

### 2. Читання (List)
Отримання списку всіх студентів:
```bash
python main.py -a list -m Student
```

### 3. Оновлення (Update)
Оновлення назви групи за її ID:
```bash
python main.py -a update -m Group --id 1 -n "КН-22"
```

Переведення студента в іншу групу:
```bash
python main.py -a update -m Student --id 1 --group_id 2
```

### 4. Видалення (Remove)
Видалення студента за його ID (через налаштований каскад будуть видалені і його оцінки):
```bash
python main.py -a remove -m Student --id 1
```
